## What "best in slot" means here

Best in slot is only meaningful with a content ceiling attached, so these plans
are written against one specific target:

- **Season 1 global launch**, release 2026-10-05, Founder access 2026-09-30.
- **Unlock and gate range 0 to about 3,800.** That is the practical ceiling, so
  a plan is "finished" when it reaches it, not when it matches a Korean endgame
  build from a later season.
- **No Heroic-grade equipment.** Heroic is not in the launch build, so the
  ceiling per slot is the best Unique-grade, crafted, quest or shop item
  available in Season 1. Where a Korean guide names a Heroic piece, these notes
  name the Season 1 substitute instead and say so.

Anything that only exists in a later Korean season is labelled roadmap. It is
worth knowing it is coming, but it is not worth planning your first month
around.

## How to read a plan

1. **Roadmap note first.** It carries the stat priority and the phase table.
   Stat priority is the decision that makes every other decision, because it
   determines which drop is an upgrade and which is vendor trash.
2. **Gear table second.** Every row names the item, its grade, its item level,
   the stats that matter, and where it comes from — dungeon and difficulty,
   boss, quest, recipe, shop and currency, or conversion route. Use it as a
   shopping list, not as a ranking.
3. **Skills and stigmas third.** Cheap power, and reversible, which makes it the
   safest place to experiment. Each Skills note has a **specialisation table**
   — which of the five specialty options to equip at 8 / 12 / 16 / 20.
4. **Support systems last, but start them early.** Arcana, Pantheon, pets,
   wings and titles are slow accumulators. They pay the most to the player who
   started them earliest, which is exactly why they are easy to under-invest in.
   Pet **farm order is the same for every class** (Intelligence camp first);
   see [[Class Pet Farm Priority]].
5. **In-game macro and hotbar columns** — native client feature (not third-party).
   Bottom of each column = highest priority skill. See
   [[In-Game Macros and Hotbar Lines]] for all eight classes; each **Skills and
   Stigmas** note repeats the class table.

Daevanion routing graphs — how to walk each board, which blue and green nodes
to take — live on [[Daevanion Boards]] and on each class's Skills and Stigmas
note.

## Where the numbers come from

These plans are derived mostly from Korean live-server play, because that is
where the only real endgame data exists. That has two consequences worth stating
plainly. Class balance shifts between regions and patches, so a stat priority is
a well-argued starting point rather than a law. And where the Korean community
genuinely disagrees, the notes present both positions with the reasoning instead
of inventing a consensus.

Every note keeps its sources at the bottom with URLs and dates, so when a patch
shifts a name or a number you can re-check that claim rather than re-researching
the class.
