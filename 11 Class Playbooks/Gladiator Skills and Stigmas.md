# Gladiator Skills and Stigmas

> **In one sentence:** keep **`Lunge Stance`** and **`Lifestealing Blade`** on the
> same cooldown bundle, use **`Rage Burst`** to enable **`Overhead Slam`**, and
> macro **`Rage Burst` → `Overhead Slam` → `Sword Aura Rampage` → `Rending Blow`**.

## Core PvE loop

1. **Buff bundle A (~42 s with ~30% CDR):** **`Lunge Stance`** + **`Lifestealing Blade`** — then inner macro.
2. **Buff bundle B (~21 s):** **`Ruinous Blow`** + **`Rage Burst`** (same duration/CD family).
3. **Party:** **`Zikel's Blessing`** on stagger or on cooldown in static groups.
4. **Macro:** hold Macro + LMB on main DPS line; **`Sword Aura Rampage`** only when stagger break procs.
5. **Manual:** **`Blade Toss`**, **`Focused Block`**, **`Defiance`**, gap **`Rush Strike`**.

## Stigmas — four slots

| Slot | Stigma | KR | Target | Role |
| --- | --- | --- | --- | --- |
| 1 | **`Lunge Stance`** | 돌격 자세 | **20** | Combat speed + crit + crit→CDR; **first shards** |
| 2 | **`Zikel's Blessing`** | 지켈의 축복 | **15** | Party ATK + multi-hit; 20 low value |
| 3 | **`Lifestealing Blade`** | 흡혈의 검 | **15** | Party leech buff; pairs with Lunge CD |

**Flex:** **`Focused Block` 5–15** replaces **`Rage Burst`** on block mechanics.
**`Wave Armor` 15** — open-world / no-healer only; weak in organized PvE.

**Shard order:** Lunge **20** → Zikel **15** → Lifesteal **15** → Rage **5…20**.

## Daevanion

Orange **CDR + combat speed** first (Nezekan), then **`Overhead Slam` / `Rending Blow`** blues, then **`Blood Absorption`** greens. See [[Daevanion Boards]].

### In-game macro (PvE)

[[In-Game Macros and Hotbar Lines#Gladiator (검성)]] — **`Rage Burst` → `Overhead Slam` → `Sword Aura Rampage` → `Rending Blow`**, 10 ms, hold + LMB. Buffs **not** in macro.

## Traps

- **`Keen Strike`** spam instead of learning **`Rage Burst`** timing — lower ceiling.
- Mobile spec on **`Rending Blow`** without practice — macro roots you if wrong spec.
