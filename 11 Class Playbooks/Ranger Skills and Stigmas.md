# Ranger Skills and Stigmas

> **In one sentence:** charge **`Deadshot`** on its own key while the macro runs
> **Griffon line → Gale line**, keep **`Vaizel's Authority`** up, and treat
> **`Marking Shot`** + **`Snipe`** as manual openers.

## Core PvE loop

1. **Buff:** **`Vaizel's Authority`** (stigma) on cooldown; party **`Bow of Blessing`** in static groups.
2. **Macro (2 steps, 10 ms, hold + LMB):** **`Griffon Arrow`** (or **`Explosive Arrow`** from 37) → **`Snare Shot`** → **`Burst Arrow`**, then **`Gale Arrow`** → **`Drill Dart`** → **`Tempest Shot`**.
3. **Manual:** **`Deadshot`** — hold charge while macro runs; **`Marking Shot`**, **`Snipe`**, traps, **`Defiance`**.
4. **Kiting:** maintain range; **`Mother Nature's Breath`** when taken as flex stigma for reflect-heavy content (later slot).
