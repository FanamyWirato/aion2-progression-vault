# Alt Routines

> **In one sentence:** Korea deleted the alt-farming meta in April 2026 by moving
> most entry counts from per character to per server, so the honest answer at
> global launch is one main plus at most one alt whose entire job is the
> 2,000,000 daily field Kinah cap — and the first thing to do on day one is spend
> thirty seconds proving whether that is still true.

## Why it matters

Every English-language AION 2 alt guide you will find was written for a game
that no longer exists. In the launch-window Korean build, a second character was
a second set of everything: another seven Daily Dungeon entries, another five
Duty Quests, another 2,000,000 Kinah cap, another set of Expedition and
Transcendence counts. People ran four and five characters and the arithmetic was
overwhelming.

Two Korean patches dismantled it. **Season 3 on 2026-04-08** cut per-character
free reward refills and moved the purchasable ticket pool, the Odyle conversion
limit and the Wind Breeze shop limit to **per server**. **Chapter 1 on
2026-07-01** reworked how entry counts are consumed. The measured outcome, from
the Inven thread that did the arithmetic at the time: going from one character to
four raised weekly reward-cube opens from about 34 to about 65.5. That is **1.9x
the reward for 4x the playtime**, and the marginal fourth character is worth
under half of the first.

So this note is mostly a warning, with a small amount of genuinely useful
residual advice attached. The useful part survives because one thing was never
made per-server: **field-hunting Kinah**, and specifically the fact that it is
the only *tradable* Kinah a character can generate in volume.

## How it works

### What is shared, and at which scope

This is the whole note in one table. Anything marked per server is a reason not
to build an alt; anything marked per character is a reason to consider one.

| Thing | Scope | Consequence for alts |
| --- | --- | --- |
| Duty Quests ×5 | **per server** (reported) | The daily loop cannot be repeated on an alt on the same server |
| Daily Dungeon entries | **per server** in the current build (reported) | The biggest bulk Enhance Stone source does not multiply |
| Odyle Energy material conversion | **per server**, 20 total, in current KR | Was 7 per character. This alone removed most of the alt case |
| Wind Breeze special tab | **per server**, 21 items | Was per character |
| Expedition / Transcendence purchasable tickets | **per server**, 21 | Was per character |
| Expedition / Transcendence free reward refills | per character (14 / 7) | The residual reason an alt earns anything at all |
| Shugo Festa keys | **per server** (reported) | No multiplication |
| Orders and Abyss Orders | **per server** (reported) | No multiplication |
| **Field-hunting Kinah, 2,000,000 per day** | **per character** | The single best reason to run an alt |
| Gathering and crafting | per character, uncapped | Multiplies freely; limited only by your hours |
| Odyle Energy pool | per character | An alt has its own passive regeneration |
| Empyrean Traces / Monolith | per character to collect, but **collection status is shared** by the succession feature | Alts inherit the main's Monolith progress rather than re-earning it |
| Abyss Points | per character | Cannot be moved to the main; only usable on the alt itself |
| Item level, gear, Arcana, skills, Stigma | per character | Nothing transfers |
| Pantheon, collections, account achievements | account-wide | An alt contributes without needing to be geared |
| Server Warehouse | per account **per server** | Same-server alts can pass Enhance Stones and materials; cross-server alts cannot |
| Bound Kinah | per character, untradable | Dungeon and quest Kinah on an alt is stuck there forever |

The two rows that matter most are the last two. **Bound Kinah is why alts stopped
being Kinah farms**, and the Server Warehouse is why an alt must be created on
your main's server or it is worth nothing at all.

### The one loop that still works

An alt at level 45 can generate **2,000,000 tradable Kinah per day** from field
hunting, and that Kinah can be moved to the main through the Server Warehouse.
Nothing else an alt does converts into main-character power at anything like
that rate.

```
One alt, run for the field cap only
  2,000,000 Kinah/day x 7 = 14,000,000 tradable Kinah/week
  for roughly 30-45 min/day = 3.5-5 h/week

What 14,000,000 Kinah buys the main
  7 Wind Breeze Odyle purchases (700,000)     = 280 Odyle Energy
  the week's 12 Orders                        ~ 600,000
  the full Abyss Order set                    ~ 1,300,000
  1 Unique Arcana refinement                  = 2,000,000
  ... and roughly 9,000,000 left for Market enhancement materials
```

Compare that with the same 3.5 to 5 hours spent on the main's uncapped gathering
and crafting pipeline, which has no daily ceiling at all. For many players the
crafting block wins outright, and the alt only wins if you have already
saturated the Market for what you can craft or if you enjoy field grinding more
than crafting.

### The residual tricks that still work

These survive the per-server rework, in descending order of value.

1. **Proxy enhancing.** Enhancement success is per attempt and failure destroys
   materials, not characters. Some players use an alt to make attempts on gear
   that the main will later receive through the warehouse, in the belief that it
   protects the main's luck streaks. This is superstition mechanically, but the
   real version is not: an alt can hold and enhance *spare* gear so the main's
   inventory and warehouse space stay free for the pieces it actually wears.
2. **Enhance Stone laundering.** Enhance Stones are warehouse-transferable, so an
   alt's free Expedition and Transcendence refills (14 and 7 per character) do
   still convert into main-character enchanting material. This is the only
   per-character reward refill left.
3. **Faction coverage.** A character in the opposing faction can gather the
   opposing faction's Empyrean Traces and see the other half of the map without
   waiting on a Spacetime Rift window. Because the Monolith succession feature
   shares collection status between your characters, this can be worth real
   Wisdom Stones — but check whether succession works across factions on your
   account before relying on it.
4. **Account-wide contribution.** Pantheon entries, collections and account
   achievements do not care which character earned them, so a low-effort alt
   still adds a little.
5. **Class scouting.** Trying a second class properly costs nothing but time and
   avoids a wasted season on a class you dislike.

### Twink utility beyond the Kinah cap (TW community guide)

If your build still gives **per-character** entries for Ascension Trial, Abyss
Corridors, and Nightmare, alts are worth more than field hunting alone. A
Taiwan-server YouTube guide ([[Twink Playbook - YouTube Ey_xTunLIg0]]) orders
work as follows.

**Always on spare slots (low time):**

- [ ] **Ascension Trial** — warehouse **binding chests** (manastones/soulstones),
  craft and deposit Arial Trace crystals *(~5 min · P1)*. **Global:** Silentium is
  **character-bound** — vendor on the alt only; it does not warehouse to main
  ([[Twink Playbook - YouTube Ey_xTunLIg0]] — global corrections table).
- [ ] **Abyss Corridors** you faction holds — tradable Kinah, AP, refining stones;
  buy Lesser Abyss manastones and warehouse for main PvP rolls *(~8 min · P1)*

**When the alt can fight PvP or solo bosses:**

- [ ] **Nightmare ×2/day** — prioritize **Amplify Stones** to warehouse; treat
  fragments as alt-banked so the **main** buys wings/skins/statues *(P2)*
- [ ] **Battleground** participation and wins — bulk AP; Asphalt Trace fragments to
  warehouse *(P2)*
- [ ] **AP skin loop (TW/full shop only):** buy PvP appearance gear → dismantle →
  Combine on main — **not on global S1** (no launch PvP gear in that pipeline) *(skip)*

**Main-first (do not drain on throwaway alts):**

- Server-wide **Daily Dungeon / Shugo Festa** (author: no twink repeat).
- **Odyle “16” server cube budget** and most purchased opens — main before twinks.
- **Four crafts × 40 Odyle** per character is real; use on alts only after main
  regen is spent.

**Account shape (author):** one main + **one** serious twink (Conquest + Kinah) +
other characters as **Trial/corridor farmers**, not four mains.

This block **conflicts** with the per-server KR model documented above. On global,
run the [[Alt Routines#Unlock and gates|verification step]] first; if Trial and
Nightmare counters are full on a fresh alt, treat this section as primary and the
“one Kinah alt only” advice as too conservative.

### What alts can no longer do

State this plainly, because it is the opposite of what older guides say:

- **An alt cannot run a second set of Duty Quests on your server.**
- **An alt cannot run a second set of seven Daily Dungeon entries.**
- **An alt cannot give you seven more Odyle conversion crafts.**
- **An alt cannot buy a second Wind Breeze special tab.**
- **An alt cannot buy a second batch of Expedition or Transcendence tickets.**
- **An alt cannot send you its dungeon or quest Kinah**, because that Kinah is
  Bound.
- **An alt cannot send you Abyss Points**, gear it is wearing, Arcana, skill
  progress or Stigma.
- **An alt on a different server cannot send you anything at all**, because the
  Server Warehouse is per server.

## Unlock and gates

- Character slots: available from creation; make the alt on your **main's
  server**, or the warehouse route does not exist.
- The field Kinah cap is only worth farming once the alt can kill efficiently,
  which in practice means level 45 and roughly item level 800-1,000.
- Expedition and Transcendence on the alt need item level 1,000, which is the
  real cost of the Enhance Stone laundering trick.
- Opposing-faction alts need a separate character; whether that counts against
  the same server's shared limits is unverified.

## Inputs: currencies, materials, sources

### The alt daily list

Twenty to forty minutes. Do this **after** the main's Express routine, never
instead of it.

- [ ] Log in, claim attendance, mail and any account-wide pass rewards that pay per character *(2 min · free · P1)*
- [ ] Glance at the alt's Odyle bar. It regenerates independently, so if it is near cap spend a claim tonight *(10 sec · free · P2)*
- [ ] Field hunt to the 2,000,000 Kinah cap in a dense spawn zone, picking a zone that also drops pet souls and gathering nodes you need *(30-45 min · daily cap per character · **tradable** Kinah, pet souls, gathering materials · P1 — this is the only reason the alt exists)*
- [ ] Gathering pass on the same route, for the main's Odyle conversion materials *(included in the above · uncapped · P1)*
- [ ] Deposit everything into the Server Warehouse: Kinah, Enhance Stones, gathering materials *(2 min · same server only · P0 — an alt that does not deposit has done nothing)*
- [ ] Spend the alt's free Expedition or Transcendence refills only if it can clear them quickly and only for the Enhance Stones *(10-15 min · 14 / 7 per character per week · Enhance Stones for the main · P2)*
- [ ] Duty Quests **only if** you have verified they are per character on global *(10-15 min · P2, or skip entirely · see Open questions)*

### The alt weekly list

- [ ] Warehouse consolidation: move the week's Kinah, Enhance Stones and materials to the main *(5 min · P0)*
- [ ] If the alt is in the opposing faction, one Empyrean Trace route segment in territory the main cannot reach *(30-45 min · one-off per trace · Wisdom Stones through Monolith succession · P2)*
- [ ] Gathering circuit on a route the main does not cover *(30-45 min · uncapped · P2)*
- [ ] Nothing else. Every other weekly item is either per server or non-transferable.

## Progression path

### How many alts make sense

| Your weekly hours | Characters | Why |
| --- | --- | --- |
| Under 8 | **1** | The main's own lockouts are not being finished. An alt is strictly negative here |
| 8-12 | **1** | Still the main's ceiling. Extra hours go into gathering and crafting, not a second character |
| 12-20 | **1, or 2 late in the season** | Consider an alt only once the main routinely ends the week with unspent Odyle and finished weeklies |
| 20-30 | **2** | One main, one field-Kinah alt on the same server. Second-best use of the hours after PvP rank |
| 30+ | **2, possibly 3** | Diminishing hard. The Inven arithmetic gives 1.9x reward for 4x the time |

The rule underneath the table: **an alt is only worth building when your main has
run out of things to spend time on, and your main runs out at about twelve hours
a week.** Before that point every hour on an alt is an hour of the main's
lockouts left unspent, which is the worst trade in the game.

### Levelling shortcut path for a new alt at Season 1

The point of this path is to reach the field-hunting cap fast and skip everything
that only pays a main.

- [ ] Create the alt **on your main's server**. Non-negotiable — the Server Warehouse is the entire value proposition *(P0)*
- [ ] Take the fastest class you have gear knowledge for, not the class you find interesting. The alt is a Kinah pump *(P0)*
- [ ] Run the main story campaign and nothing else. It is the fastest experience per minute in the game and it carries the level-gated system unlocks with it *(several hours · P0)*
- [ ] Ignore side quests, collections and exploration on the alt. Monolith collection status is shared through succession, so the main already banked most of it *(P0)*
- [ ] Warehouse the alt a starter gear set from the main's leftovers instead of enhancing anything. The alt needs enough item level to kill field mobs quickly and no more *(15 min · P1)*
- [ ] Take every account-wide and one-time reward that is offered on the way, including growth-support and level-milestone packs *(P1)*
- [ ] Stop deliberately at the point where the alt can clear the 2,000,000 Kinah cap in about 30 minutes. Do not gear past that. Every Enhance Stone spent on the alt is one not spent on the main *(P0)*
- [ ] Optional, only if you want opposing-faction Empyrean Traces: make the alt in the other faction and accept that the warehouse route may be restricted *(P3 · unverified)*

### Value per alt per week, honestly

| What one alt returns per week | Value | Effort |
| --- | --- | --- |
| Field-hunting Kinah | 14,000,000 tradable | 3.5-5 h |
| Enhance Stones from 14 + 7 free reward refills | one week of a second character's stone income | 1-2 h, plus the cost of gearing the alt to item level 1,000 |
| Gathering output | uncapped, but so is the main's | proportional |
| Empyrean Traces the main cannot reach | one-off, real but finite | 1-2 h total, once |
| Abyss Points, Arcana, gear, skills | **zero to the main** | — |

Total realistic transfer: **14,000,000 Kinah and a stack of Enhance Stones for
about five hours a week.** Judge that against five hours of crafting on the main
before you commit.

## Priorities and breakpoints

- **Verify before you build.** Thirty seconds on day one settles it: create a
  second character, open the Duty Quest journal, and see whether it offers 5 or
  0. Do the same for the Daily Dungeon entry count and the Odyle conversion
  charges. If they read full, the pre-April-2026 alt meta is live on global and
  this entire note is obsolete in your favour.
- **Same server or nothing.** The Server Warehouse is the only transfer route.
- **The alt's job is Kinah, not power.** Do not enhance, tune, soul-imprint or
  refine anything on an alt.
- **Never let alt play displace main lockouts.** The alt runs after the main's
  Express routine, or not at all.
- **Bound Kinah is the wall.** Everything an alt earns inside instances is stuck
  on that alt permanently. Only field hunting, gathering and Market sales produce
  Kinah that moves.
- **Reconsider at the season transition.** Season resets change entry counts more
  than any other event; re-run the verification above each season.

## Traps and mistakes

- **Building an alt on advice written before 2026-04-08.** Almost every English
  alt guide in circulation is pre-Season-3 and describes per-character limits
  that no longer exist in Korea.
- **Creating the alt on a different server** and discovering the warehouse cannot
  reach it.
- **Gearing the alt.** Enhance Stones spent on an alt are permanently lost value
  unless the alt is genuinely your second main.
- **Expecting dungeon Kinah to transfer.** It is Bound. Only field, gathering and
  Market Kinah moves.
- **Farming Abyss Points on an alt.** They are per character and unusable
  anywhere else.
- **Running alts before the main's weeklies are finished.** The most common and
  most expensive alt mistake.
- **Assuming the per-server model on faith.** It is very likely but unconfirmed
  for global, and the cost of being wrong is high in both directions — build no
  alts when you should have built two, or waste a week levelling one that cannot
  do anything.
- **Soul-imprinting anything on an alt.** Imprinted gear can never move back
  through the warehouse. See [[Soul Imprint and Soul Binding]].

## Global launch notes

**This is the least certain note in the chapter, and the uncertainty is
structural.** Global launches on 2026-10-05 with a Season 1 content build, but
NC has not said whether the *systems* around that content are the launch-window
Korean systems or the current ones. Those two answers give opposite alt advice:

| If global ships... | Then... |
| --- | --- |
| Korea's **launch-window** per-character limits | Alts are extremely strong. Four characters is defensible and every English guide you have read is correct |
| Korea's **current** per-server limits | Alts are marginal. One main plus one Kinah alt, as this note describes |

This vault assumes the second, because global launches eleven months after the
Korean release and NC has generally shipped global with current systems and
launch content. But it is an assumption, and it is the highest-value thing on
this page to check yourself.

Two further wrinkles specific to global:

- **Cross-server play changes the meaning of "per server".** Global is reported
  to use large cross-server clusters for the Abyss and matchmaking. If lockouts
  are counted per *server* while content is matched per *cluster*, the practical
  scope of a per-server limit may differ from Korea's.
- **The membership is a single $15 tier globally**, and its Korean equivalent
  carries the Odyle regeneration and cap uplift. If the global membership carries
  those benefits, one subscribed main out-earns two free characters on energy
  alone.

See [[Global Launch Differences]] and
[[Alts and Account Wide Progression]].

      Festa keys, Orders and Odyle conversion crafts per character or per server
      on global? Settled in thirty seconds on day one by opening the same UI on a
      second character.
- [ ] Whether the Server Warehouse works between characters of opposing factions
      on the same account.
- [ ] Whether Monolith collection succession shares status across factions, which
      is the entire case for an opposing-faction alt.
- [ ] Whether the 2,000,000 daily field Kinah cap exists on global at the same
      value, and whether field Kinah is still tradable rather than Bound.
- [ ] Whether Nightmare attempts and Ascension Trial entries are per character. No
      source states either way after the per-server rework, and if they are per
      character the alt case improves considerably.

      slots are purchasable.
