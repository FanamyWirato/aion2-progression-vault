# Twink Playbook — YouTube Ey_xTunLIg0

> **In one sentence:** a Taiwan-server player’s ordered checklist for what to run
> on twinks and what moves through the Server Warehouse — **with global release
> corrections** where Silentium and the AP→PvP-gear→skin loop do not apply.

**Source:** [Twinking guide (German)](https://www.youtube.com/watch?v=Ey_xTunLIg0) —
deep dive on Abyss Points and twink utility from about [11:32](https://www.youtube.com/watch?v=Ey_xTunLIg0&t=692s).
Full transcript (machine captions): `agent-tools/Ey_xTunLIg0_transcript.txt`.

**Vault context:** [[Alts and Account Wide Progression]] and [[Alt Routines]] describe
the **Korean post–Season 3** alt meta (mostly per-server lockouts). This guide
assumes **many entries still scale per character** (Ascension Trial on every twink,
Nightmare tickets per twink, separate Odyle pools). Treat it as a **mechanics
menu** and verify each counter on your build before copying the schedule.

**Global launch:** character level cap **45** (not the author’s **55** on TW).
Names below use English vault terms; the video uses German UI labels (Abis Points =
Abyss Points, Episal = Abyss, Fantasen Fragmente = Phantasmal Fragments).

## Why it matters

Twinks are not only a second **2,000,000 tradable Kinah** field cap. The author’s
model is: **farm per-character currencies and warehouse-transferable materials on
cheap alts**, then **spend character-bound rewards on the main** (wardrobe skins,
Pantheon statues, wings) while **routing tradable goods through the Server
Warehouse**.

## Author’s priority ladder (easiest first)

| Order | Activity | Time (author) | Main benefit |
| --- | --- | --- | --- |
| 1 | **Ascension Trial** | ~3–5 min per run | Binding chests, Arial Trace overflow; Silentium only **on-character** Kinah on global |
| 2 | **Abyss Corridors** (3 types, faction-held gates) | ~2.5 min each | Tradable corridor Kinah, AP, refining stones; PvP manastones for main |
| 3 | **Abyss field grind** (optional) | varies | More AP and Kinah; Arial crystals for twink PvP slots if you have hours |
| 4 | **Abyss Points → PvP gear → dismantle → combine on main** | medium | **TW/KR shop only** — not global S1 (see above) |
| 5 | **Battleground** | low if queued | Bulk AP, Asphalt Trace fragments (warehouse) |
| 6 | **Arena** | only if extra time | Smaller AP (participation / win caps) |
| 7 | **Nightmare** | 2 tickets/day | **Transferable** Amplify Stones; bank fragments for main’s shop spends |
| 8 | **Odyle crafts + dungeons** | main-first | Extra cube opens only after main is fed |
| 9 | **Proxy enhance / Soulwinding** | as needed | Kinah and material savings on main gear |

**Recommended account shape (author):** one **main** (all Odyle and “serious”
progression), **one leveled twink** for Conquest and tradable Kinah routes, **other
slots** mostly for Ascension Trial + corridors only — not four fully geared alts.

## Activity notes

### Ascension Trial

- Solo difficulty ladder; rewards scale with twink gear.
- **Silentium:** author warehouses it on TW; **5,000 Kinah** each at junk NPC, up to
  **~160,000** per run at top tier (theoretical max). **Global:** character-bound —
  same NPC price but **only on that alt**, no warehouse.
- **Superior Ascension Binding Chest:** warehouse — **manastones and soulstones** for
  main gear tuning.
- **Enhance Stones / Stigma shards:** per character; keep on twink.
- **Arial Trace fragments:** not storable raw; craft **Arial Trace crystals** (warehouse
  + Market). When boards are full on all chars, sell crystals for tradable Kinah.
- Author: **minimum** activity on **every** spare character slot.

### Abyss Corridors

- Short solo instances; need your faction to **hold** the corridor.
- Pays **tradable Kinah**, **Abyss Points**, occasional refining stones.
- Buy **Lesser Abyss manastones** with AP on the twink; stones are warehouse — roll
  **PvP stats** on main gear.
- Optional: open-world Abyss mob grind on twink for AP/Kinah and crystals **for that
  twink’s** PvP slots (field crystals are character-bound per author).

### Abyss Points — skins and collection power (TW / full Abyss shop)

**Skip this block on global S1** — no PvP appearance gear in the launch shop to
buy and dismantle. AP on twinks is still per character; spend it on **launch-
available** sinks (see [[Abyss Points and Ranks]], [[Merit Medals]]) or accept
that alt AP is mostly alt-local until the shop expands.

On Taiwan / full shop builds:

- **Collection effect:** each unlocked skin raises passive bonuses for that equipment
  slot (example cited: ~17% defense contribution from helm skins).
- Loop on twink: earn AP → buy PvP appearance gear → **Dismantle** → Unique skin
  part + **80% AP refund** → **Combine on main** (wardrobe server-wide).
- **Wings** and **medals** stay on the character that earned them.

### Battleground and Arena (AP)

| Reward | Amount (author) |
| --- | --- |
| Battleground participation | **2,000 AP × 3** claims per cycle shown |
| Battleground victory | **5,000 AP × 3** wins |
| Arena participation | **500 AP**, up to **10** times |
| Arena wins | **1,000 AP**, up to **30** wins per week |

Battleground also drops **Asphalt Trace** fragments — treat like Arial Trace: craft,
warehouse, or sell. Medals are twink-local.

### Nightmare (Phantasmal Fragments)

- **2 attempts per day**, solo boss, Layer 1 = Season 1 band in video.
- Shop currency: **Phantasmal Fragments** (author’s “Fantasy fragments”).
- **Amplify Stones:** **Server Warehouse** — primary twink→main transfer (Potential /
  amplification pipeline).
- **Soul Crystals:** cheap in shop (**50** fragments, **10** purchases per week cited);
  used for **Genus Insight** rerolls (**per server / account** scope in UI).
- **Wings, skins, statues, grade gear** from the same shop are **character-bound** —
  author farms fragments on twinks so the **main** spends **main’s** fragments on
  wings, skins, and **Pantheon** statues instead of Amplify Stones.

### Odyle Energy and dungeon cubes

- **Odyle → material craft:** **4 crafts per character** (= **40** energy) — real
  per-character multiplier.
- **Server-wide “16” cube-open budget** (author): spend on **main**, not twinks.
- **Membership:** extra purchasable opens (**16 per server** at **100,000 Kinah** each
  in video); author buys **4 per twink** only after main is covered.
- **Dungeon Kinah icon:** **silver** = Bound Kinah on lower/outdated tiers; **gold** =
  tradable on current-season tiers. When content ages, expect Bound-only.
- **Reward efficiency:** not “83 runs” but **83 cube opens**; diminishing returns
  after thresholds (author: 100% → 80% → 60% bands).
- **Regen math (with sub):** **15** energy / 3 h → **~120/day** → **~3 cube opens/day**
  → **~21 opens/week** from regen alone per character, before crafts and purchases.

### Per-server — do not repeat on twinks

Author states these do **not** multiply by twink (server/account scope):

- **Daily Dungeons**
- **Shugo Festa**
- **Beritra / world boss key events** (keys not per-character in the sense of free repeats)

Confirm in UI on global; if true, twink time is better spent on Trial, corridors,
Nightmare, and field cap — not duplicating main weeklies.

### Proxy enhancing and Soulwinding (advanced)

1. **Enhance soulbound main gear on twink:** warehouse gear to twink → twink cannot
   wear if imprinted to main → **enhancement still works** → warehouse back. Spend
   twink’s **Bound Kinah** and stones.
2. **Manastone / soulstone slots:** use stones farmed on twink for rolls on **main**
   pieces held via warehouse workflow.
3. **Transfer enhancement value:** obsolete **soulbound** main gear can feed twink
   gear upgrade paths (author: Kinah savings vs buying fresh).
4. **Substat rerolls:** twink dungeon drops you cannot use → **Soulwinding / Sync**
   UI can consume them to reroll **subst stats on main gear** (author demo).

See also [[Soul Imprint and Soul Binding]] — first equip on main still permanently
binds; never equip twink-bound drops on main if you intend to trade.

## Leveling cost (author, TW)

- **45 only:** ~4–6 h active push.
- **45 + scent / side progression:** ~6–7 h average.
- Video prerequisite **level 55** for end twink loop — **not applicable** on global
  cap **45**; use **45 + item level gates** instead ([[Season 1 Launch Plan]]).

## Traps and mistakes

- **Assuming four alts × full dungeon weeklies** — author explicitly rejects this
  post–Bound Kinah / cube-efficiency changes; feed main first.
- **Buying Amplify Stones on main while ignoring twink Nightmare** — wastes main
  fragment budget if main also wants wings/statues.
- **Planning alt AP around skin dismantling on global** — that gear is not in the
  launch build.
- **Expecting Silentium from four alts on the main** — on global, each alt vendors
  its own Silentium; it does not stack on the main via warehouse.
- **Combining skins on twink** (TW) — wardrobe collection is **server-wide**; combine
  on **main** so collection progress applies where you wear gear.
- **Equipping tradable drops on main** before warehousing to twink — soul imprint
  blocks trade and alt workflows.
- **Copying KR post-2026-04-08 per-server limits from this vault without checking** —
  if global matches TW author experience, alt value is **higher** than [[Alt Routines]]
  assumes; if global matches current KR, skip duplicated weeklies and focus Trial,
  corridors, field cap, and proxy tricks.
