# Aion 2 Progression Vault

Obsidian knowledge base for **Aion 2 global Season 1** progression: gear, skills,
routines, class playbooks, economy, and launch differences vs the Korean live
servers.

**Start here:** open [`Home.md`](Home.md) in Obsidian (or any Markdown viewer).

## What this is

- Researched notes from KR/TW live data, aligned to the **2026-10-05 global launch**
  (level cap 45, Season 1 scope).
- Wikilink-style cross-references (`[[Note Title]]`) — best in [Obsidian](https://obsidian.md/).
- English skill names checked against the global client where noted in class playbooks.
